Practice 9 – Pygame Projects

Description:
This practice includes several small projects created using the Pygame library.
Each project demonstrates different aspects of working with graphics, animation, time, and sound in Python.

Projects:

1. Moving Ball
A simple animation where a ball moves across the screen using keyboard controls.

Features:
- Ball movement with arrow keys
- Screen boundaries control
- Real-time rendering

2. Mickey Clock
A clock application inspired by Mickey Mouse.
The hands of the clock rotate according to the current system time.

Features:
- Real-time clock (minutes and seconds)
- Rotating clock hands
- Image transformation (rotation, scaling)
- Pygame graphics

3. Music Player
A basic music player with keyboard controls.

Features:
- Play and stop music
- Switch tracks (next / previous)
- Display current track name
- Show playback time
- Progress bar
- Object-oriented design (MusicPlayer class)

Controls (Music Player):
P - play
S - stop
N - next track
B - previous track
Q - quit

Technologies:
- Python 3
- Pygame

Run:
Each project should be run separately from its folder:

py -3.13 main.py

Notes:
- Images are required for the Mickey Clock project (images folder)
- Music files should be placed in the "music" folder for Music Player
- Supported audio formats: .mp3, .wav
