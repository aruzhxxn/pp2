# Practice6

This repository contains Python practice exercises for file handling, directory management, and built-in functions.

## Structure

- **file_handling/**: examples of reading, writing, copying, and deleting files.
- **directory_management/**: examples of creating directories and moving files.
- **builtin_functions/**: examples using `map`, `filter`, `reduce`, `enumerate`, and `zip`.
